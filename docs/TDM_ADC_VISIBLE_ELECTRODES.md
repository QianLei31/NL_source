# TDM ADC Visible Electrode Map

This table lists every ADC/global channel and the routed local electrodes visible in TDM mode.

Rule:
- Each block has 16 electrodes.
- Each ADC/global channel maps to 4 local electrodes inside the block: local ELE `0`, `1`, `2`, `3`.
- Blocks where `block % 8` is `0..3` expose local ELE pair `02`.
- Blocks where `block % 8` is `4..7` expose local ELE pair `13`.
