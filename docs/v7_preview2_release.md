## 本轮功能

- **全事件流档案**：直接接收检测线程的不可变事件和波形，不从有限显示 ring 轮询。保存 run UUID、事件 ID、源帧坐标、物理电极、换算增益、实际检测/分类版本；人工改标签使用追加式历史日志
- **可重新打开的档案**：有界分页、按电极/epoch/源时间查询、波形和标签历史；后台校验、取消和损坏尾部的只读有效前缀恢复。不会修补或覆盖原始采集文件
- **持续波形盒分类**：每个候选可组合多个 AND 框；规则可保存/载入 JSON，并在处理边界应用于后续事件。跨块等待后窗的事件保留穿越时的原规则。重叠候选明确为 ambiguous，配置不匹配明确为 incompatible
- **独立离线分析**：专用读取→检测→写盘通道，队列满时背压等待，不经过显示用可丢弃订阅队列。支持分卷、TDM、有效性信息、取消、读/写失败，以及 EOF 排空后独立重开检查
- **正常停止排空**：源接收/分发结束后，等待检测消费已接收输入，再等待档案写完。单独停止档案不会等待慢磁盘而阻塞持续检测。最终提交阶段明确不可取消
- **原界面设计恢复**：新窗口使用原应用主题、间距和控件风格；修复浅色主题黑底不可读、禁用按钮仍显高亮、主题切换清空保留波形、紧凑窗口文字裁切等问题

## 与 Open Ephys 的位置

本轮补上了“全事件档案＋独立离线无损处理”和“保存波形盒规则并分类后续事件”这两个闭环。详细原版/preview1/preview2 对照见 [功能对照](open_ephys_feature_comparison.md)。

仍没有 PCA/多边形分选、MED/MAD 噪声估计、参考/坏道掩码、多电极联合波形、TTL/PSTH、标准 SpikeInterface/NWB/Phy 适配或自动神经元分选。波形盒与人工 ID 都是候选分组，不代表已经验证单神经元隔离。

## 关键语义

1. 实时开档只记录开档之后输出的完整波形窗口；不能补回开档前事件。显示留存仍有容量限制，档案独立保存
2. `Completed` 表示本次档案的写入和结束标记已完成。源缺口、未验证数据、无效帧、边界排除和中途开档另行报告，不能由该状态推出源数据完整
3. TDM 每电极采样率为源帧率的 1/4；当前实时和离线检测仍处理选中的 512/1024 物理电极，相位身份写入事件
4. 换算增益仍是人工统一设置。没有真实板卡校准、模拟噪声或刺激效果验证
5. 修改检测配置/参考/TDM、清空或 seek 会结束当前档案区间。规则修改本身可在线生效并保留实际版本历史；回放使用当前明确配置，不会自动重演任意历史参数脚本
6. 离线取消保留已接受并排空的可验证前缀，结果标为取消。进入最后的接受尾部提交后，取消按钮关闭；不会把无效取消请求显示成已取消

- 新档案核心涵盖慢写、队列满、故障注入、取消、损坏尾部、超限记录、语义损坏标签及精确大整数身份

以上是具体测试证据，不是生物 spike sorting 准确率。原 Quiroga 标准数据检测结果仍见已有验证报告，不能把宽诊断盒的功能验证解读为标准数据的分选准确率。

## 重现

标准 CMake/Qt 项目流程：

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_TESTING=ON
cmake --build build -j4
QT_QPA_PLATFORM=offscreen ctest --test-dir build --output-on-failure -j1
```

构建需要 Qt Core/Gui/Widgets/Network/OpenGL/OpenGLWidgets/Concurrent 和现有 OpenSSL。未增加新的运行时第三方包。
